# Glider v0.1.0 release audit

This milestone completes the master project plan through rolling deployments,
service discovery, observability, CLI operations, chaos/security/performance
testing, and the final demonstration.

Release gates:

- `scripts/test-linux-runtime.sh` — build, vet, unit, race, and privileged Linux integration.
- `scripts/test-chaos.sh` — repeated convergence and fencing invariants.
- `scripts/test-security.sh` — adversarial isolation and supply-chain checks.
- `scripts/benchmark.sh` — reproducible scheduler and DNS baselines.
- `scripts/demo.sh` — embedded-etcd scheduling, readiness, discovery, and rolling-update demonstration.

Known boundary: the CLI reserves `logs`, `exec`, and `stats`, but the node
streaming transport is not part of v0.1.0; these commands fail explicitly.
Glider remains an educational pre-production platform and must not be treated
as a replacement for a security-maintained production orchestrator.
