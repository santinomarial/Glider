# Code of conduct

Glider welcomes respectful questions, contributions, and technical disagreement.
Participants should explain feedback with evidence, respect different levels
of experience, and focus criticism on ideas and code.

Harassment, threats, discriminatory abuse, sexual harassment, and publishing
another person's private information are unacceptable. These expectations
apply to the project's issues, pull requests, reviews, and other spaces the
maintainer operates for Glider.

The maintainer may edit or remove abusive content, lock discussions, or restrict
participation in response to violations. Responses should consider severity,
context, and repeated behavior.

To report abuse privately on GitHub, use the platform's
[abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Do not post private evidence in a public issue. Glider does not currently
operate a separate confidential community-reporting inbox.
